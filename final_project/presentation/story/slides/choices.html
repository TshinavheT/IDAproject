Why we built it this way

Five design choices, and the reason for each

ChoiceWhy
Predict next year’s auditTreasury needs time to act before the outcome is decided
Split the data by yearLearn from the past, test on the future: exactly how it will be used
Logistic RegressionAs accurate as the neural networks, more stable, and every score can be explained
Macro-F1 as the main scoreA missed failing municipality and a false alarm both have real costs
A dashboard, not a spreadsheetOfficials move from a national view to one municipality in two clicks

Seeing municipal audit failure coming · 7 · Presenter: P Khosa

Presenter: P Khosa. Each choice follows from how the product will be used. We predict one audit cycle ahead because a prediction of a result that is already decided is useless. We split by year so testing mirrors real use. We picked Logistic Regression because the more complex models were no more accurate, were less stable, and are harder to explain to an official. Macro-F1 balances missed cases against false alarms. And a dashboard lets officials explore rather than read a static list.
